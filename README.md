## Estructura

```
index.html          Página completa (HTML + CSS)
site.webmanifest    Permite instalarla como app en el celular
vercel.json         Configuración de Vercel
robots.txt          Permite que Google la indexe
assets/             Logo, íconos e imagen para compartir en redes
```

## Publicar en Vercel

1. Sube esta carpeta a un repositorio nuevo en GitHub.
2. En vercel.com → **Add New → Project** → importa el repositorio.
3. Framework Preset: **Other**. No hace falta comando de build ni carpeta de salida.
4. Pulsa **Deploy**.
